# 🚀 Nome do Projeto

Essa aplicação trata-se de uma aplicação Progressive Web App (PWA), desenvolvida para permitir a instalação da aplicação em dispositivos como celulares, tablets, pcs. Permite tambem navegação mesmo quando estiver sem acesso à internet.

## 🚀 Link do Aplicativo para instalação

https://pwa-gamer.netlify.app/

---

## 🛠️ Tecnologias utilizadas

- **Linguagem  HTML5, CSS3, JavaScript
- **Recursos PWA:** Web App Manifest, Service Workers, Cache Storage API
- **Ambiente de Execução e Teste:** Node.js

---

## 📁 Estrutura do projeto

```text
├── index.html        # Interface e estrutura principal da aplicação
├── style.css         # Estilos de formatação   
├── app.js            # Logica da aplicação
├── manifest.json     # Metadados da PWA (nome, ícones, cores, display)
├── sw.js             # Service Worker responsável pelo suporte offline e cache
├── README.md         # Documentação do projeto
└── icons/            # Ícones 
```
---

## 💻 Como rodar em modo desenvolvimento usando Node

Pré-requisitos
Certifique-se de ter o Node.js instalado em sua máquina.

Passo a passo
Clone o repositório:

``` Bash
git clone [https://github.com/seu-usuario/seu-repositorio.git](https://github.com/seu-usuario/seu-repositorio.git)
```


Acesse a pasta do projeto:
```Bash
cd seu-repositorio
```

Suba um servidor local com Node (via npx):
```Bash
npx serve .
```

Acesse a aplicação:
Abra o navegador e acesse o endereço fornecido no terminal (geralmente http://localhost:3000 ).
